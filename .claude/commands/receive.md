상대 PC가 보낸 핸드오프 데이터를 받아 이 PC를 활성화한다: $ARGUMENTS

절차:
1. 사용자에게 받은 zip 파일의 경로를 확인한다 (인자로 없으면 물어본다)
2. `make receive FILE=<경로>` 실행 — 기존 data/는 자동 백업되고,
   명세(문서·claim 건수)와 실제 건수를 대조해 검증한다
3. 검증 결과를 보고한다. 불일치 경고가 나오면 상대에게 재내보내기를 요청하라고 안내
4. 성공 시: 이 PC가 활성이 되었음을 알리고, `make stats`로 최종 확인
5. 수집 스케줄이 이 PC에 등록되어 있는지 확인하고, 없으면 등록을 제안한다
