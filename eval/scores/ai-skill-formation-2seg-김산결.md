**L1은 2026-09-17 재설계했다.** 1차·2차에서 예/아니오 질문이 의도대로 읽히지 않아(판정은 "아니오", 사유는

| 검사 | 질문 | 답 | 사유 |
|---|---|---|---|
| L1 코어 선명성 | 이 코어의 논지를 **가장 불편해할 역할 하나**를 고르십시오 — 리더 / 팀원 / 없음. ("없음"이면 코어가 둥글다는 뜻이고, 그때만 미달이다) | | |

| L3 시점 차이 | 두 레이어가 "같은 말을 대상만 바꾼 것"이 아니라 각 자리에서만 보이는 인사이트를 담았는가 (예/아니오/중립) | | |
