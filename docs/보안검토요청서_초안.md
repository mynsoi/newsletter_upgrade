# 보안성 검토 요청서 (초안)

> 제출 전 확인: 검토 주관 부서명, 신청 양식 유무, 담당자를 확인 후 본 초안을 해당 양식에 맞게 이관.
> 목표: Phase 0 첫 주 내 제출 (기획서 13.2-1, 유일한 외부 의존 병목).

## 1. 검토 요청 개요

| 항목 | 내용 |
|---|---|
| 과제명 | AI 시대 일하는 방식 인사이트 콘텐츠 파이프라인 구축 |
| 요청 부서 | (기재) |
| 요청 내용 | 사내한(B등급) 문서의 외부 LLM API(Anthropic Claude) 전송 승인 |
| 희망 회신 기한 | (제출일 + 검토 표준 소요기간 기재) |

## 2. 처리 대상 데이터

| 구분 | 내용 | 전송 여부 |
|---|---|---|
| A등급 (공개) | 대외 공개된 SKMS 자료, 공개 연설·인터뷰, 지속가능경영보고서 | 전송 (본 검토 대상 아님) |
| **B등급 (사내한)** | 사내 공지, 경영층 사내 메시지, 사내 제도 문서 | **본 검토의 승인 대상** |
| C등급 (기밀) | 미공개 전략, 인사 정보 | 전송 금지 — 시스템이 색인 단계에서 코드 레벨 차단 |

- 승인 전까지 B등급은 사내 서버 내 저장·색인만 수행하며 외부 전송하지 않음 (시스템 플래그로 강제, 기본값 차단).
- 개인정보(구성원 개인 식별 정보)는 어떤 등급에서도 처리 대상에 포함하지 않음.

## 3. 데이터 흐름

```
사내 서버 (수집·저장·색인: SQLite + 파일)
   └─ HTTPS(TLS) ─→ Anthropic Claude API (아티클 생성·분석 요청)
                      └─ 응답(생성 텍스트) ─→ 사내 서버 저장
```

- 전송 구간: TLS 암호화 (HTTPS)
- 전송 데이터: 프롬프트에 포함되는 문서 본문 및 메타데이터
- 전송 주기: 주 1회 아티클 생성 시 + 일 1회 외부 공개 자료 분석 시

## 4. 검토 요청 항목 (기획서 4.1)

아래 4개 항목에 대한 확인·승인을 요청함. 각 항목의 근거 자료는 제출 시점의
LLM 제공사 공식 문서를 확인하여 최신본으로 첨부한다.

1. **입력 데이터 학습 미사용**: API 입력 데이터가 제공사의 모델 학습에 사용되지 않는다는
   정책 확인 (상용 API 약관 및 데이터 사용 정책 첨부)
2. **데이터 보존·삭제**: API 요청 데이터의 보존 기간, 삭제 옵션,
   제로 데이터 리텐션(ZDR) 계약 가능 여부 확인
3. **전송·저장 암호화**: 전송 구간 및 제공사 측 저장 시 암호화 방식
4. **계약 조건**: 엔터프라이즈 계약 체결 시 적용 가능한 데이터 처리 부속 계약(DPA),
   리전 옵션, 감사 인증(SOC 2 등) 현황

## 5. 자체 통제 장치

| 통제 | 구현 방식 |
|---|---|
| C등급 원천 차단 | 색인 코드가 `security: C` 파일을 거부 (본문 미열람) |
| B등급 전송 게이트 | 설정 플래그 기본값 차단, 승인 문서번호 기록 후에만 해제 |
| 접근 통제 | 내부 자료 디렉토리 별도 권한, 저장소 버전관리에서 내부 자료 본문 제외 |
| 감사 추적 | 모든 전송 대상 문서에 등급·적격 플래그 기록, 변경 이력 git 관리 |
| 산출물 통제 | 발행 전 담당자 승인 게이트 필수 (완전 자동 발행 없음) |
