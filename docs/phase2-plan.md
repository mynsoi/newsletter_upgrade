## 운영 규칙

- **당번**: 미지정 — Phase 2는 개발 단계이므로 작업자가 유동적으로 진행
- **일일 수집·enrich**: 자동 지속 (Actions 매일 06:00, enrich_enabled: true).
  enrich는 상한 1000건을 **① 그날 수집분(최신 순) → ② 남는 칸으로 백로그(티어별
  라운드로빈)** 순으로 쓴다 (2026-09-09). 경계는 `collection_runs`의 최근 `started_at`.
- **arXiv 백로그 소진**: 옛 "보류 계층 3"은 2026-09-09 해제 — 별도 실행 없이 위 ②단계가
  매일 소진한다. 하루 약 $4, 잔여 11,459건 기준 2주 남짓 예상. 소진 완료 후에는 ②단계가
  자연히 비고 일일 비용도 유입분만큼으로 내려간다. 미룰 필요가 생기면 daily 단계에
  `--exclude-sources 'arxiv-*'`를 걸면 된다.
- **월간 브라우저 라운드**: 10월 초 예정 (`/browse-round`)
- **월간 소스 리뷰**: 9월 말 — 시험 기간(trial_until 2026-09-30) 만료 소스 정식/퇴출 판정
- **머지 규칙** (동료 병행 개발): 머지 전 상호 통지 + `make test` 통과 필수
