블록 1 — DB를 PostgreSQL로 전환
```
DB를 Supabase PostgreSQL로 전환하자. 환경변수 DATABASE_URL이 설정돼 있어.
1) psycopg 의존성 추가. src/db.py를 DATABASE_URL 있으면 PostgreSQL, 없으면 SQLite로
   동작하는 이중 지원 구조로 수정 (로컬 테스트는 SQLite 유지 목적).
2) migrations를 PostgreSQL 호환으로: FTS5 가상 테이블 3종은 제거하고 텍스트 컬럼에
   pg_trgm GIN 인덱스 + 검색 함수로 대체 / documents는 raw_path 대신 body TEXT 컬럼에
   원문 직접 저장(수집기·추출기·스팟체크 절차도 body를 읽도록 수정) / 나머지 테이블 동일.
3) SQLite 모드 테스트 전부 통과 확인 + DATABASE_URL 모드로 Supabase에 스키마 생성 검증.
```
