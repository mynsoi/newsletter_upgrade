칼럼 작업실은 이렇게 돌아갑니다

버튼은 스크립트를 부르고, 스크립트는 AI를 부르고, 단계와 단계 사이는 전부 파일로 이어집니다.

내 컴퓨터에서 돌리려면

cd mentor-lab/app && npm install && npm run build
cd .. && python3 -I scripts/studio_server.py 8771
# → http://localhost:8771

서버는 이 컴퓨터(localhost)에서만 열립니다. 화면 코드만 고쳤으면 다시 빌드만 하면 되고, 서버 코드를 고쳤으면 돌고 있는 작업이 없을 때 재시작합니다.

필요한 것

  • Python 3 · Node.js — 서버와 화면
  • claude (Claude Code) — 과정 1 초안, 진행자 대화
  • codex + gpt-6-astra — 주제 지도, 제목, 과정 2부터, 그림 설명
  • gti (god-tibo-imagen, gpt-6-astra) — 그림
  • aside — 브라우저로 Threads · LinkedIn 원문 수집
