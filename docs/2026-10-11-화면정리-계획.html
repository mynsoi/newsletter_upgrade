화면 정리 계획

글 화면을 대화 화면 하나로 합칩니다. 예전 글 화면(제목·과정·그림·확정 탭, Article.tsx 797줄)에만 있던 기능 6개를 대화 화면으로 옮긴 뒤 예전 화면을 지웁니다. 서재·주제 지도·스크립트·데이터는 건드리지 않습니다.

1. 대화 화면으로 옮길 기능 예전 화면에만 있던 것

기능예전 자리대화 화면에서
비교과정 탭오른쪽 '지금 글' 위에 보기 버튼 본문 · 비교 · 미리보기. 비교는 앞 과정에서 바뀐 문장에 형광 표시.
확정 미리보기확정 탭같은 보기 버튼의 미리보기 — 머리 그림과 고른 본문 그림이 제자리에 들어간 완성본(종이 모양). 미리보기에서 지금 보는 과정으로 확정(예전 확정 탭처럼).
분량 절반 (쓴 뒤에)글 위쪽 줄지금은 쓰기 전에만 고를 수 있음 → 오른쪽 위에 대상 독자 · 기본/절반을 늘 두기. 쓴 뒤 절반을 누르면 최신 과정을 절반으로 줄인 과정이 대화에 붙음(예전과 같은 동작). 기본/절반은 기준 글에도, 대상 독자는 설정 글만.
제목 다시 뽑기 (말 없이)제목 탭지금은 말을 보내야만 다시 뽑힘 → 대화의 마지막 제목 카드에 다시 뽑기.
본문 그림 자리 · 지난 그림 회차그림 탭그림 카드의 본문 그림마다 문단 N 칩과 이름, 지난 회차는 접어 두기.
기준 글(퇴근 시간 칼럼) 편집과정 · 확정 탭지금은 편집 버튼이 설정 글에만 → 기준 글에도(예전처럼 과정으로 쌓임).

2. 지울 것

  • app/src/views/Article.tsx 전체. 대화 화면이 같이 쓰던 조각(본문 그리기·진행자 창·본문 그림 자리 찾기)은 새 파일 views/parts.tsx로 옮김.
  • 대화 화면 위쪽의 제목 · 과정 · 그림 · 확정 링크.
  • 예전 주소 #/a/<글>/<탭>은 지우지 않고 대화 화면으로 열리게 — 주제 지도의 "이 주제로"나 북마크가 깨지지 않게.
  • 서버 동작 retry(새 글로 다시 쓰기) — 같은 대화 안의 "처음부터 다시 쓰기"로 바뀌어 화면에서 안 씀.
  • 예전 화면을 가리키는 설명 — handoff 5절의 "글 — 탭 제목/과정/그림/확정", README와 그 캡처(docs/readme/screen-column.jpg)를 대화 화면 기준으로 바꿈.

3. 같이 정리할지 정해 주실 것 안 정하시면 그대로 둡니다

A. 주제 지도 아래 "이전 방식 회차 4"10/9~10에 쓰던 옛 주제 후보 방식(runs/topics)을 보여 주는 접힌 칸과, 그걸 돌리던 서버 동작 topics·pick-topic. 기록 파일은 남기고 화면·동작만 지움.
B. 8770 예전 비교 화면view/를 띄운 서버. 작업실(8771)과 달리 같은 공유기(LAN)에도 열려 있음. 끄기만 함(파일은 남김).
C. 안 쓰게 되는 컴포넌트 파일예전 화면만 쓰던 Timeline · 카드 호버 · 단계 로더 · 아코디언 등. 제안: 지우지 않고 둠(참고 사이트에서 설치한 것이라 다음에 다시 쓸 수 있음).

4. 순서와 확인

  1. 조각을 parts.tsx로 옮기기 (동작 변화 없음)
  2. 대화 화면에 기능 6개 넣기
  3. 주소를 대화 화면으로 돌리고 Article.tsx 지우기 → 빌드·타입 검사
  4. 헤드리스 브라우저로 직접 눌러 확인
    • 자기평가 글(지금 과정 4)에서 비교 · 미리보기 · 오른쪽 위 독자/분량 표시 — 이 글은 보기만 하고 바꾸지 않음
    • 퇴근 시간 기준 글 열기(과정·확정이 대화로 보이는지) · 주제 지도에서 "이 주제로" → 대화 화면 · 예전 주소 #/a/…/process → 대화 화면
    • 절반 · 제목 다시 뽑기 · 편집은 시험용 복사본으로 (끝나면 휴지통까지 지움)
  5. 화면 시험 스크립트 바꾸기 — 지금 handoff의 화면 시험 wiki-eval/ui_e2e.py는 예전 탭을 눌러서 예전 화면을 지우면 깨짐. 오늘 대화 흐름 시험(요청 → 이어서 말하기 → 제목 → 쓰기 → 피드백 → 편집·이어 쓰기·다시 쓰기 → 삭제)을 저장소 스크립트로 옮겨 대신하게 하고, 시험 글 이름·휴지통 비우기까지 스크립트가 하게. handoff 7절 안내도 바꿈.
  6. 작업실 서버 재시작 — 돌고 있는 작업이 없을 때만
  7. 커밋 하나로 묶어 푸시 — 문제가 생기면 그 커밋 하나만 되돌리면 예전 화면이 돌아옴

모델을 부르는 확인은 절반 줄이기·제목 다시 뽑기 두 번뿐입니다(astra, 합쳐 2분 안팎). 예상 시간은 1시간 안팎입니다.
