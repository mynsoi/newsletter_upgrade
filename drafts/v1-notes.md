# v1 피드백 — 영어 수사 구조가 그대로 나옴 (2026-10-07)

멘토 반응: "not a but b 문체 벌써부터 나온다. 영어를 직역해서 번역한 말투."

| v1 문장 | 밑에 깔린 영어 구조 |
|---|---|
| 줄어든 건 쓰는 시간이었고, 늘어난 건 확인하는 시간이었습니다 | What decreased was X; what increased was Y (강조 구문) |
| 효율은 AI가 얼마나 빨리 쓰느냐보다, ~에서 갈립니다 | It's less about X than Y (not A but B) |
| 그렇다고 AI를 덜 쓰자는 얘기는 아닙니다 | This doesn't mean we should ~ (양보 후 반전) |
| 틀린 말은 아닙니다. 다만 ~ | That's not wrong. But ~ |
| 더 눈여겨볼 건 ~라는 점이에요 | What's more striking is that ~ |
| 이런 일은 생각보다 흔합니다 | This is more common than you think |
| 하나만 따져 보면 됩니다. ~가. | Just ask yourself one question: ~ |
| AI가 줄여 준 시간이 그대로 내 시간으로 남습니다 | 경구형 마무리 한 줄 |

원인 메모:
- 모델 습관 — 영어 비중이 큰 학습 데이터의 수사 구조(대비·강조 구문·양보 후 반전·경구 마무리)를 한국어로 옮긴다.
- 지시 탓 — "흔한 생각 → 바뀌는 생각" 뼈대 자체가 "A가 아니라 B"를 부른다.

v2에서 바꾼 것: 일이 일어나는 순서대로 서술, 결론은 한 번만 평범하게, 대비·강조 구문 제거.
